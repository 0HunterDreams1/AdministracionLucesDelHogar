# AdministracionLucesDelHogar

Aplicación Android para controlar las luces del hogar de forma remota. Este proyecto integra una app móvil con hardware basado en Arduino (NodeMCU) para demostrar el control inteligente de la iluminación en el hogar.

## Características

- Encendido y apagado de luces desde la app Android.
- Control remoto a través de conexión WiFi.
- Integración con NodeMCU para la parte física.
- Interfaz intuitiva y fácil de usar.
- Soporte para diferentes habitaciones y tipos de luces.

## Tecnologías utilizadas

- **Kotlin** (Android)
- **C++** (NodeMCU/Arduino)
- **NodeMCU** (ESP8266)
- **Gradle**

## Instalación

1. Clona este repositorio:
   ```bash
   git clone https://github.com/0HunterDreams1/AdministracionLucesDelHogar.git

1. Abre el proyecto en Android Studio.
2. Configura tu dispositivo NodeMCU con el código correspondiente (ver carpeta nodeMCU_archive/Wifi_NodeMCU).
3. Conecta la app con tu red WiFi y el NodeMCU.

### Uso
1. Abre la app en tu dispositivo Android.
2. Selecciona la habitación o luz que deseas controlar.
3. Usa los botones para encender o apagar las luces.
